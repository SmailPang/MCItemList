## ✨ 项目简介

**MCItemList** 是一款简洁、直观的本地工具，  
用于打开与管理我的世界投影模组导出的材料清单文件。  
无需联网即可使用，方便个人玩家或小型服务器进行离线备货统计。

如果你希望进行**多人协作或在线处理**，请使用：  
👉 [MCItemListOnline（在线版）](https://github.com/Akttoer/MCItemListOnline)

---

## 🚀 快速开始

### 🪟 Windows

1. 前往 [Releases 页面](https://github.com/Akttoer/MCItemList/releases) 下载最新版本  
2. 解压压缩包  
3. 双击运行 **`main.exe`**

---

### 🍎 macOS / 🐧 Linux

1. 前往 [Releases 页面](https://github.com/Akttoer/MCItemList/releases) 下载最新版本  
2. 安装 **Python**  
3. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

4. 运行程序：

   ```bash
   python main.py
   ```
